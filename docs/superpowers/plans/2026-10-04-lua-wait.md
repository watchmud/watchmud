**Goal:** `wait(n)` in a mob's fight hook runs the rest of the hook n pulses later, one
hook per mob at a time, dropped if the mob or its fight is gone -- so the Barrow-King
says his line, pauses two seconds, then his guard rises.

**Architecture:** Every hook runs as a gopher-lua coroutine (`NewThread` + `Resume`),
each resume under its own deadline. `wait` is a Go global that yields; the runtime keeps
the suspended run in an ordered slice, and `Runtime.Tick` -- called each pulse from the
heartbeat through `World.ResumeScripts`, before violence -- counts it down and resumes
it if the world says the mob is still fighting.

**Tech Stack:** Go, gopher-lua v1.1.2 coroutines, testify, testdice.

**Spec:** `docs/superpowers/specs/2026-10-04-lua-wait-design.md`

## Global Constraints

- `make check` green before every commit; one commit per task, on master.
- `wait(seconds)`: a whole number 1..`script.MaxWait` (10); only inside a hook; one
  pulse (`rules.PulseInterval`, 1s) per second.
- `script.MaxWaitPerCall` = 30 seconds total per hook run; past it is an error and a strike.
- One hook at a time per mob: while one waits, that mob's hooks don't fire.
- A wait ends early, silently (not a failure), when the mob leaves the world, its fight
  is over at the moment the wait comes due, or its program reaches `MaxFailures`.
- After a wait `me.health` and `me.summons` are re-read; `foe` is unchanged.
- The per-call caps (says, summons) and the stale-`me` check span the whole hook run.
- Every resume under a fresh `CallTimeout`.
- `ResumeScripts` runs every pulse, before violence.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

`script/sandbox.go`, beside `call` (which stays: a program's top level still loads

```go
// resume runs th -- starting fn with args the first time, carrying on where
// it yielded after that -- under a fresh CallTimeout, with h as the hook in
// progress. done is false when the hook yielded (wait) rather than
// finished. An error, a timeout, a stack overflow or a panic come back as an
// error; none of them escape.
func (s *sandbox) resume(th *lua.LState, fn *lua.LFunction, h *hookCall, args ...lua.LValue) (done bool, err error) {
	ctx, cancel := context.WithTimeout(context.Background(), CallTimeout)
	defer cancel()
	th.SetContext(ctx)
	s.current = h
	defer func() {
		s.current = nil
		th.RemoveContext()
		if r := recover(); r != nil {
			err = fmt.Errorf("panic: %v", r)
		}
	}()
	state, err, _ := s.L.Resume(th, fn, args...)
	switch state {
	case lua.ResumeError:
		return false, err
	case lua.ResumeYield:
		return false, nil
	}
	return true, nil
}
```

`script/runtime.go`:

```go
// hookRun is one hook running on one mob, from its start to its end, across
// any waits: its own coroutine, the call its caps and its me belong to.
type hookRun struct {
	mob  *mobile.Instance
	lp   *loaded
	hook string
	fn   *lua.LFunction
	th   *lua.LState
	call *hookCall
	me   *lua.LTable
}

func (r *Runtime) fire(mob *mobile.Instance, hook string, foe Foe) {
	lp := r.programs[mob.Definition.Script]
	if lp == nil || lp.failures >= MaxFailures {
		return
	}
	fn, ok := lp.env.RawGetString(hook).(*lua.LFunction)
	if !ok {
		return
	}
	call := &hookCall{
		roller: r.roller,
		say:    func(text string) { r.actions.Say(mob, text) },
	}
	// Its own coroutine, so it can yield: a hook can't know in advance whether
	// it will reach a wait.
	th, _ := r.sb.L.NewThread()
	run := &hookRun{mob: mob, lp: lp, hook: hook, fn: fn, th: th, call: call, me: r.me(mob, call)}
	r.run(run, run.me, r.foe(foe))
}

// run starts or carries on a hook run -- args start it -- and deals with
// how it ended.
func (r *Runtime) run(run *hookRun, args ...lua.LValue) {
	if _, err := r.sb.resume(run.th, run.fn, run.call, args...); err != nil {
		r.fail(run, err)
	}
}

// fail counts a failed run against its program, switching the program off at
// MaxFailures.
func (r *Runtime) fail(run *hookRun, err error) {
	lp := run.lp
	lp.failures++
	r.logFailure(fmt.Errorf("script %s, mob %s, %s (failure %d of %d): %w",
		lp.program.name, run.mob.Definition.Id, run.hook, lp.failures, MaxFailures, err))
	if lp.failures == MaxFailures {
		log.Warn().Str("script", lp.program.name).Msg("script disabled until restart")
	}
}
```

Walkthrough points: why the deadline goes on the *thread* (`SetContext` is what
switches a state to the loop that checks it; the thread runs its own loop); why
`L.Resume` is called on the main state (the parent the thread yields back to); why
`call` survives for loading (a top level must never yield, and doesn't need a thread);
why `NewThread`'s cancel func is ignored (it's nil when the parent has no context, and
ours has none between calls).

```go
// wait(seconds) suspends the hook in progress: it yields out of the hook's
// coroutine, and Runtime.Tick resumes it that many pulses -- seconds -- later.
func (s *sandbox) wait(L *lua.LState) int {
	n := L.CheckNumber(1)
	h := s.running(L, "wait")
	secs := int(n)
	if lua.LNumber(secs) != n || secs < 1 || secs > MaxWait {
		L.RaiseError("wait: %v is not a whole number of seconds from 1 to %d", n, MaxWait)
	}
	if h.waited+secs > MaxWaitPerCall {
		L.RaiseError("wait: more than %d seconds of waiting in one call", MaxWaitPerCall)
	}
	h.waited += secs
	h.wait = secs
	return L.Yield()
}
```

`script/runtime.go` -- `hookRun` gains `pulses int // left to wait`; `Runtime` gains
`waiting []*hookRun // in the order they began waiting`. `run` files a yielded run:

```go
func (r *Runtime) run(run *hookRun, args ...lua.LValue) {
	done, err := r.sb.resume(run.th, run.fn, run.call, args...)
	switch {
	case err != nil:
		r.fail(run, err)
	case !done:
		run.pulses = run.call.wait
		r.waiting = append(r.waiting, run)
	}
}

// Tick is one pulse for every hook run waiting on wait(), in the order they
// began waiting. One that comes due carries on, with me's health and summons
// read fresh. inFight is the world's answer to "is this mob still in a
// fight?" -- see Task 3.
func (r *Runtime) Tick(inFight func(*mobile.Instance) bool) {
	var due, still []*hookRun
	for _, run := range r.waiting {
		run.pulses--
		if run.pulses > 0 {
			still = append(still, run)
		} else {
			due = append(due, run)
		}
	}
	r.waiting = still
	for _, run := range due {
		r.refresh(run.mob, run.me)
		r.run(run)
	}
}

// refresh re-reads what me copies that can change while a hook waits.
func (r *Runtime) refresh(mob *mobile.Instance, me *lua.LTable) {
	me.RawSetString("health", lua.LNumber(mob.CurHealth))
	me.RawSetString("summons", lua.LNumber(r.actions.Summons(mob)))
}
```

and `Runtime.me` sets `health` and `summons` by calling `r.refresh(mob, me)` instead of
its two `RawSetString`s, so there is one place that knows which fields go stale.

Walkthrough points: why `L.Yield()` is the whole trick (a Go function returning it
suspends the coroutine that called it; `Resume` returns `ResumeYield`); why the wait
check comes after `s.running` (a top-level wait must fail as "only inside a hook");
why `Tick` splits into `due` and `still` before resuming anything (a resumed run may
wait again and append to `r.waiting` -- never modify a slice you're ranging); why
`refresh` writes into the *same* `me` table (the hook holds that table in a local; a
new one would never reach it).

// isWaiting is whether mob has a hook run waiting on wait().
func (r *Runtime) isWaiting(mob *mobile.Instance) bool {
	return slices.ContainsFunc(r.waiting, func(run *hookRun) bool { return run.mob == mob })

// ResumeScripts carries on every script that's done waiting, if the mob
// running it is still in a fight -- see script.Runtime.Tick.
func (w *World) ResumeScripts() {
	w.scripts.Tick(func(mob *mobile.Instance) bool {
		return w.roomOf(mob) != nil && w.fightLedger.InFight(mob)
	})
}
